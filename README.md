RPG Project - Java + JavaFX
===========================
This skeleton demonstrates OOP structure and TXT-based config loading.

Build & Run (using Maven):
  mvn clean javafx:run

Requirements:
  - Java 22 JDK
  - JavaFX 24 (maven plugin downloads it)

Configs:
  resources/config/enemies.txt
  resources/config/items.txt
  resources/config/rules.txt
